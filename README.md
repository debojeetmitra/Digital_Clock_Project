# 🕒 Digital Clock using HTML, CSS & JavaScript

A simple and responsive **Digital Clock Web App** built using **HTML, CSS, and JavaScript**.  
This project displays the current local time (Hours, Minutes, Seconds) and updates in real-time using JavaScript's `Date` object.

## 📌 How It Works

- JavaScript gets current time using `new Date()`  
- Extracts hours, minutes, and seconds  
- Updates the UI every second using `setInterval()`  
- Displays live time on screen
